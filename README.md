# FIRST Value · Property Assessment Console

Concept prototype by **Team Sapiens** (Pallav Kumar, Tejas Gupta, Deepak Lal · DMS, IIT Delhi) for the IDFC FIRST Bank FAME 6.0 Open Innovation Challenge, Problem Statement 1: faster, cheaper property valuation for Loan Against Property.

Live: https://pallav3198.github.io/first-value-dashboard/

Tabs: portfolio overview · today vs FIRST Value · case journey with property knowledge graph · valuer workbench · business case calculator.

All data is illustrative and anonymised. This is not an IDFC FIRST Bank product.
